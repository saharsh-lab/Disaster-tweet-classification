Engineering & NLP Architecture

Classification Methodology

End-to-end pipeline architecture detailing text normalization, recurrent sequence modeling, and low-latency serverless vector inference.

Operational NLP Inference Pipeline
Step-by-step Transformation
01
Social Signal Ingestion
Raw incoming tweets and crisis dispatches are ingested via REST API payloads or real-time streaming connectors.
Input: Raw UTF-8 String (1–280 chars)
02
Text Preprocessing & Regex Cleaning
URLs, usernames, hashtag symbols, and non-alphanumeric noise are stripped using compiled regex patterns. Standard domain stopwords are filtered out.
clean_text = re.sub(r'http\S+|@\w+|[^a-z\s]', '', text.lower())
03
Tokenization & Sequence Padding
Tokens are mapped to integer word IDs using a 5,000-word vocabulary index. Out-of-vocabulary words map to index 1 (). Arrays are post-padded to 30 tokens.
Matrix Output: int32 vector shape (30,)
04
Word Vector Embedding
Each token index is mapped to a 64-dimensional dense semantic embedding matrix, capturing contextual disaster relationships.
Tensor Shape: (30, 64) continuous floating-point representation
05
Bidirectional LSTM Core
Processes the sequence bidirectionally (64 units forward + 64 units backward) with input, forget, candidate, and output gating mechanisms, concatenating final hidden states.
Concatenated Hidden Vector: (128,) state vector
06
Dense Layer & Sigmoid Activation
Passed through a Dense ReLU layer (32 units) followed by a single sigmoid unit producing a calibrated probability score [0.0, 1.0].
prob = 1 / (1 + exp(-logit)) • Decision Threshold = 0.50
07
Resource Extraction & Operational Dispatch
If classified as an emergency request (prob ≥ 0.50), a lexical resource analyzer extracts critical needs (Water, Medical Aid, Shelter, Food, Rescue) and dispatches telemetry.
Output: Telemetry record tagged with confidence & required resource
